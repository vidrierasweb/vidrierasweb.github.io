# Vidrieras Web

Sitio de **Vidrieras Web**: webs y catálogos para comercios y emprendimientos de Argentina.

**En vivo:** https://vidrierasweb.github.io/

## Qué es
Una página estática (HTML, CSS y un poco de JavaScript, sin frameworks ni dependencias).
La idea visual es una vidriera de local: toldo rayado, marco de vidrio y etiquetas de precio.

## Archivos
| Archivo | Para qué sirve |
|---|---|
| `index.html` | Toda la página (estilos y script incluidos) |
| `logo.png` | Logo del menú y del pie |
| `favicon.png`, `apple-touch-icon.png` | Íconos de la pestaña y del celular |
| `og-image.png` | Imagen que se ve al compartir el link |
| `maximo.jpg` | Foto de la sección "Quién soy" |
| `demo-*.jpg` | Capturas de los ejemplos y de los casos reales |

## Diseño
- **Colores:** negro `#0B0B0D`, gris azulado `#15181F`, azul `#2F6BFF` (acento), azul claro `#7FA6FF` y blanco `#FFFFFF`.
- **Tipografías (Google Fonts):** Outfit para títulos y precios, Figtree para el texto.

## Cómo se actualiza
Los cambios se hacen sobre `index.html` y se suben a la rama `main`. GitHub Pages
publica solo, desde la raíz del repositorio.
